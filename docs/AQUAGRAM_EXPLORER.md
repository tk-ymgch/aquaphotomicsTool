# Aquagram探索

Workbench v1.9.0の「Aquagram探索」は、現在の解析から得た試料別座標を使います。時系列に沿った断面の積層、選択試料のレーダー、座標ヒートマップ、座標別推移を共通の選択位置で確認できます。画面の色・余白・操作は既存Workbenchに合わせています。

## データと尺度

解析を実行してから探索画面を開きます。Aquagramの座標数・実波長・AUC帯域・モード・単位は、その解析の設定と結果を引き継ぎます。試料ごとの値は、群平均を補間したものではなく、同じ処理で集約前に計算した値です。参考HTMLの参加者データ、図から逆算したSD、固定されたモデル係数はアプリへ組み込んでいません。

標準化、対照群との差、温度校正は選択した解析方式に従います。探索で系列を絞っても標準化を再計算しません。全フレームで共通の尺度とゼロ基準を使い、負の値も保持します。ゼロのリングと幾何学的な中心は異なります。C1〜C12や特定の水分子種を、任意の波長へ自動的に対応づけません。

既存のR本体参照ブリッジは群平均のみを検証する経路です。R結果へPythonの試料別値を混ぜず、この経路で試料別探索を利用できない場合は群平均Aquagramを表示します。

## 系列と時間

系列に使うメタデータ列を明示して、参加者・条件・元ファイル等を絞ります。元ファイル名から参加者を断定する処理は行いません。表示したい時刻列と単位を選ぶか、Unity同期後の秒を使います。時刻情報を選ばない場合は「試料順」です。再生倍率は表示速度であり、取得頻度や測定時間を変更しません。表示用に断面を間引く場合も、元の試料別値は保持します。

同じ時刻が繰り返される記録や分単位の記録では、より細かな時刻を復元できません。時刻の並べ替えは表示上のID対応を保持して行います。

## 観測指数と参考モデル

座標をまとめる指数は、選択した解析座標のRMS（平方平均二乗根）です。分子の個数、特定状態の存在割合、共通分子状態の観測値とは解釈しません。

任意の参考モデルは、表示した指数に単調増加の指数曲線を当てはめます。初期値と遅延を固定し、振幅と時定数を最小二乗で推定します。

`y(t) = b + A (1 − exp(−max(0, t − t0 − d) / τ))`

ここで `A ≥ 0`、`τ > 0` です。重複時刻は平均して異なる時刻を等重みとし、6点以上が必要です。既知の参加者の係数を初期値や既定値として流用しません。表示する変化率はこの曲線の解析微分で、実測値の微分ではありません。単位は秒、または試料順に対応します。適合が悪い場合や観測期間より時定数が長い場合は、その限界を表示します。分子形成過程や反応速度の推定を保証するものではありません。

## 保存

試料別の座標は `data/aquagram_sample_values.csv`、座標定義・元メタデータ・ID順は `aquagram_samples.json` に保存します。表示で選んだ系列・時間軸・尺度・選択位置と、任意モデルの適用状態も記録してください。測定データは通常のブラウザー解析で外部へ送信しません。
