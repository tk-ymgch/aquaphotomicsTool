# フェーズ別測定とUnityログの比較

Workbench v1.8.0は、既存の単一CSV・Excel解析に加え、Baseline・Task・Recoveryのスペクトルを結合し、Unityログと時刻を合わせて比較します。測定値とUnityログはブラウザー内のPythonで処理します。公開ビルドには利用者の測定データを含めません。

## 読込と解析

実験データの画面で3フェーズのCSVと任意のUnity CSVを選び、ファイルの割当を確認します。波長列が対応するデータを結合し、フェーズ・元ファイル・元IDの情報を保持します。結合後のIDはフェーズ間で重複しません。グループ列をフェーズにすれば、既存の前処理・PCA・Aquagramで3条件を比較できます。

## 時刻の対応

Unityの経過秒だけでは、測定CSVの日時との対応は決まりません。Unityの0秒に相当する測定時刻を指定し、その根拠を確認してから同期します。開始時刻や測定間隔を手動設定する場合も、設定を結果と一緒に保存します。ログを実験全体へ引き伸ばす処理は行いません。

測定CSVの時刻精度も確認してください。分単位の日時から秒単位の測定順を復元することはできません。ログと重ならない窓や有効値のない窓は欠測として保持し、補間して観測値として扱いません。同期の集計窓と時間ずれは画面で調整できます。

## 生理指標の解釈

瞳孔径・視線方向・眼の開閉度から、測定ごとの時間窓とフェーズごとの集計を作ります。非有限値や不正な測定値を除外し、有効数・観測範囲を確認できるようにします。視線の指標は装置の座標系に依存し、画面上の注視点や注視対象を自動判定するものではありません。

眼の開閉度から検出するのは「瞬き候補」です。閾値・持続時間・ログの欠落を考慮しますが、トラッキングの喪失と真の瞬きを完全には識別できません。検出数を検証済みの生理学的瞬目数として扱わないでください。

指標とPCAスコア・波長ごとのスペクトル値を対応させ、散布図と記述的な相関を表示します。反復測定の独立性、多重比較、時系列自己相関を補正した因果推論や有意差検定ではありません。同じ参加者の測定をPLSへ利用する場合は、目的に応じて参加者単位の交差検証を指定してください。

## aquap2との関係

この取込・時刻同期・Unity生理指標集計はWorkbench独自の機能です。aquap2の移植対象や本体との互換性検証に含めません。aquap2pyは0.3.0の条件限定の部分移植のままで、完全互換フラグはfalseです。

結果のCSV・JSONとグラフを保存し、元データ、時刻の対応根拠、集計設定を研究記録として一緒に管理してください。
