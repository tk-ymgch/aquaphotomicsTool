人工スペクトルの動作確認用サンプル

synthetic_spectra.csv   UTF-8 BOM付きCSV
synthetic_spectra.xlsx  Excel形式（「人工スペクトル」「説明」の2シート）
synthetic_spectra.xls   BIFF8 Excel形式（同じ2シート）

いずれも45試料、人工群 A/B/Cの3群、1300〜1600 nmを5 nm間隔で並べた61波長です。
数値はpython/workbench.pyのdemo_dataset()で固定乱数seed=20261021から生成しています。
幅広いガウス形状と雑音を組み合わせた人工データであり、実測スペクトル、既知化学種、
臨床情報、濃度や温度の校正を表していません。実験結果として利用しないでください。

data_origin列と群名に人工データであることを記録しています。
XLSX/XLSでは「人工スペクトル」シートを選択してください。

動作確認の設定例:
  試料ID: sample_id / 群: group
  散乱補正: SNV / 平滑化: 有効 / SG窓幅: 11 / 多項式次数: 2 / 微分: 0
  PCA成分数: 3 / 波長スケーリング: 無効
  Aquagram指定波長: 1340, 1360, 1380, 1410, 1440, 1450, 1460, 1475, 1490, 1510, 1525, 1550
  基準: 全体平均 / 許容誤差: 2.5 nm

Aquagramは標準化した群平均差です。軸から特定の分子種を同定する機能はありません。
